# AI/ML Internship Assignments — Decodelabs

Curated repository containing the source code, data pipelines, and documentation for my assigned tasks during the Decodelabs AI/ML Internship.

## Portfolio Summary

* **Task 1: Rule-Based Chatbot** [`./Task-1-HafsaKhalid`](./Task-1-HafsaKhalid)
  * **Tech:** Python, Regular Expressions
  * **Highlights:** Built an interactive command-line conversational agent designed to parse natural language inputs, maintain intent matching, and gracefully handle fallback responses.

* **Task 2: Supervised Classification Pipeline** [`./Task-2-HafsaKhalid`](./Task-2-HafsaKhalid)
  * **Tech:** Python, Scikit-Learn, Pandas, NumPy, Jupyter
  * **Highlights:** Implemented an end-to-end Machine Learning workflow covering exploratory data analysis, feature scaling, train-test splitting, model training, and performance validation using standard evaluation metrics.

* **Task 3: Content-Based Recommendation System** [`./Task-3-Hafsa Khalid`](./Task-3-Hafsa%20Khalid)
  * **Tech:** Python, Scikit-Learn, TF-IDF Vectorizer, Cosine Similarity, Pandas
  * **Highlights:** Built an interactive recommendation engine that analyzes natural language user preferences and maps them to educational content using text vectorization and similarity scoring.

* **Task 4: Optical Character Recognition (OCR) App** [`./Task-4-Hafsa Khalid`](./Task-4-Hafsa%20Khalid)
  * **Tech:** Python, EasyOCR, OpenCV, Matplotlib, PyTorch
  * **Highlights:** Developed an image text recognition application that detects and extracts text from images, bounding bounding box annotations visually onto the source image.
